# TravelBloom – Travel Recommendation Web Application

A responsive travel recommendation website built with HTML, CSS and JavaScript for the IBM final project.

## Features
- **Home** page with an introduction, navigation bar, search bar, Search and Clear buttons
- **About Us** page with company information and team members
- **Contact Us** page with a name, email and message form
- Keyword search that reads `travel_recommendation_api.json` with `fetch()`:
  - `beach` / `beaches` → beach recommendations
  - `temple` / `temples` → temple recommendations
  - a country name (`Australia`, `Japan`, `Brazil`) → city recommendations
- Each result shows two images with descriptions and the current local time
